## 💥 套路一：伪 IPLC 专线（公网中转伪装内网）

真正的 **IPLC (International Private Leased Circuit)** 是在租用的跨国物理内网专线，**不过 GFW 防火墙**。

### 假 IPLC 的常见手法：
1. **公网 DNS 伪装命名**：把普通的阿里云/腾讯云公网中转节点名字改成 `🇭🇰 香港 IPLC 01`，让用户误以为是专线。
2. **晚高峰直接露馅**：由于走的依然是国际公网出口，一旦遇到 21:00 晚高峰或敏感时期，丢包率瞬间飙升至 30% 以上，节点直接红字。

```
  真 IPLC 架构：用户 -> 国内入口 -> [物理内网专线 (不过 GFW)] -> 境外出口 (丢包 0%)
  伪 IPLC 架构：用户 -> 国内入口 -> [公网加密中转 (过 GFW)]   -> 境外出口 (晚高峰严重丢包)
```
